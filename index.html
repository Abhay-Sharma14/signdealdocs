    Master System Prompt for SignDealDocs.com

    Copy this prompt and paste it into Cursor Agent / Claude to generate the complete production codebase

    Build a production-ready, full-stack multi-language SaaS web application for "SignDealDocs.com" — an All-in-One AI Proposal Generator, Digital E-Signature, and Client Document Upload Portal for global freelancers and agencies.

TECH STACK:
- Framework: Next.js 14+ (App Router, TypeScript, Tailwind CSS, Lucide Icons)
- Auth & Database: Supabase (PostgreSQL + Google OAuth & Magic Link login)
- File Storage: Cloudflare R2 (S3-compatible presigned URLs for secure drag-and-drop client uploads)
- AI Engine: Google Gemini API (@google/generative-ai) to transform rough meeting notes into structured Scope of Work JSON
- Internationalization (i18n): next-intl supporting English (en), French (fr), German (de), Japanese (ja), and Spanish (es), plus multi-currency formatting (USD, EUR, JPY, GBP, INR)
- Payments & Billing: Lemon Squeezy webhooks ($19/month Pro Plan & $49 Lifetime Deal; 3 free deals on Starter tier)
- Email Notifications: Resend API to alert agency owners when a client signs or completes document uploads

CORE ARCHITECTURE & PAGES TO BUILD:
1. Landing Page (/) & Auth (/login):
   - High-contrast Linear/Stripe-inspired SaaS landing page explaining the 3-step workflow: AI Proposal -> E-Sign -> Client File Vault.

2. Agency Studio Dashboard (/dashboard & /dashboard/new):
   - Allows agency user to customize their brand accent color, enter Client Name, Client Email, Language, Currency, Rough Project Notes, and Itemized Pricing Milestones.
   - Allows defining a custom Client Document Upload Checklist (e.g., "High-Res Logo SVG", "Tax/VAT ID", "Brand Guidelines").
   - Clicking "Generate with AI" calls POST /api/ai/generate-scope and returns structured JSON (Summary, Deliverables array, 3-Phase Timeline, Terms) in the chosen language.
   - Publishes a unique passwordless public Magic Link: signdealdocs.com/p/[slug].

3. Public Client Magic Link Portal (/p/[slug]):
   - Top 3-Step Progress Stepper: (1) Review Scope -> (2) Digital E-Signature -> (3) Upload Project Docs.
   - Step 1 & 2: Displays clean proposal document + HTML5 Canvas signature pad (draw or type). Submitting stores signature PNG in R2, logs UTC timestamp + IP + SHA-256 audit hash in Supabase, and unlocks Step 3.
   - Step 3 (Document Upload Vault): Unlocks immediately after signing. Supports real drag-and-drop file uploads directly to Cloudflare R2 via presigned URLs with progress bars.
   - When 100% of required files are uploaded, displays a verified completion receipt and triggers a Resend email notification to the agency.

Start by initializing the Next.js TypeScript project, creating the Supabase database schema (profiles, deals, deal_items, checklist_docs), and building the Agency Studio + Client Magic Link UI.
